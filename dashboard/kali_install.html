📡 KALI INSTALLATION NODE GUIDE

SECURITY COMMAND CENTER OPERATOR PROTOCOL
⚠️ WARNING: DO NOT WIPE WINDOWS

To keep your current Personal Security Suite dashboard, files, and Windows OS intact, we will configure a Dual Boot installation. Please follow the partitioning step carefully!

STEP 1 Rufus ISO Burner
  1. Open the Rufus utility on your desktop.
  2. Select your 32GB USB drive in the Device dropdown.
  3. Click Select and choose your downloaded Kali Linux installer ISO.
  4. Ensure the partition scheme is set to MBR (or GPT depending on system defaults) and target is BIOS or UEFI.
  5. Click START at the bottom. Once finished, it will read READY. Unplug the USB.
STEP 2 Shrink D: Drive Partition

Kali needs empty, unallocated disk space to install itself. We will take some space from your 34GB free D: drive partition.

  1. Press Win + X on Windows and select Disk Management.
  2. Locate your D: Drive volume block in the bottom list.
  3. Right-click on it and choose Shrink Volume.
  4. In the shrink input box, enter 25000 (makes a ~25GB space).
  5. Click Shrink. You will now see a black volume box labeled Unallocated Space. Leave it empty!
STEP 3 Boot into the USB Installer
  1. Plug the bootable USB back into your PC.
  2. Select restart or shut down.
  3. As the PC boots up, immediately tap the F12 key rapidly (the Acer boot menu trigger).
  4. In the boot menu, select your USB Flash Drive and press Enter.
  5. Select Graphical Install from the GRUB menu.
🛑 STEP 4: Disk Partitioning (CRITICAL)

When the installer asks how you want to partition the disks:

  1. Do NOT select "Guided - use entire disk" (that wipes Windows!).
  2. Choose **Guided - use the largest continuous free space**.
  3. This tells Kali to install itself directly inside the Unallocated space we shrunk in Step 2. Your Windows partition will remain completely untouched.
  4. Proceed with default files layout, write changes to disk, and authorize GRUB bootloader installation when prompted.
STEP 5 Start NetHunter Agent

Once logged into Kali Linux, open the terminal and launch the agent node:

  1. Clone/copy the agent script or run:
    sudo apt update && sudo apt install -y python3-pip pip install requests
  2. Open the nethunter_agent.py script file and verify line 16 points to your Host IP:
    SERVER_URL = "http://192.168.1.10:8767"
  3. Launch the agent surveillance loop:
    sudo python3 nethunter_agent.py

The Kali Linux machine will now show up green in your main dashboard select list and activate the remote shell!

Security Hardening Guide

Follow these steps to maximize your protection. Run harden_windows.ps1 to automate many of these.

CRITICAL
🔥

Run the Hardening Script

Run scripts\harden_windows.ps1 as Administrator. It automatically locks down Windows Firewall, disables legacy protocols, enables audit logging, and more.

PowerShell -ExecutionPolicy Bypass -File scripts\harden_windows.ps1
HIGH
🔐

Enable 2FA on All Accounts

Two-factor authentication stops 99.9% of automated attacks. Enable it on: Google, Microsoft, banking, social media, and any email accounts.

  • Use an authenticator app (Google Authenticator, Authy)
  • Avoid SMS 2FA — SIM swapping is a real threat
  • Save backup codes in a safe place
HIGH
🛡️

Use a VPN for Public Networks

Your internet traffic is visible on public WiFi. A VPN encrypts it end-to-end.

  • Recommended: ProtonVPN (free tier), Mullvad, or Windscribe
  • Enable "kill switch" so traffic stops if VPN drops
  • Never use free VPNs — they sell your data
HIGH
🔒

Use a Password Manager

Reusing passwords is how most accounts get hacked.

  • Free: Bitwarden (open source, excellent)
  • Paid: 1Password, Dashlane
  • Use a unique, 16+ character password for every site
  • Enable breach alerts in your password manager
MEDIUM
📡

Secure Your Router

  • Change the default router admin password
  • Use WPA3 or WPA2 encryption (never WEP)
  • Disable WPS (easily brute-forced)
  • Enable the router firewall
  • Create a separate Guest network for IoT devices
  • Update router firmware regularly
MEDIUM
🌐

Enable DNS-over-HTTPS

Encrypts your DNS lookups so your ISP can't see what sites you visit.

Settings → Network & Internet → DNS → Use Custom DNS → 1.1.1.1 → Enable DNS-over-HTTPS
MEDIUM
💾

Encrypt Your Drive

BitLocker prevents data theft if your device is stolen.

Control Panel → System & Security → BitLocker Drive Encryption → Turn On
LOW
📱

Android Security Tips

  • Keep Android and apps updated
  • Only install apps from the Play Store
  • Enable "Find My Device"
  • Use a strong PIN or biometrics
  • Review app permissions regularly
  • Enable Google Play Protect
